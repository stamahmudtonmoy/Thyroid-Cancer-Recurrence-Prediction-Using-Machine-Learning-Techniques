# Thyroid-Cancer-Recurrence-Prediction-Using-Machine-Learning-Techniques

## 📌 Project Overview

This project aims to predict the recurrence of thyroid cancer using machine learning techniques applied to structured clinical and demographic data. Early prediction of recurrence can support clinicians in identifying high-risk patients and improving follow-up strategies.

This work was conducted as an academic machine learning project in the healthcare analytics domain.

## 🎯 Objectives

* Explore and analyze thyroid cancer patient data
* Perform data preprocessing and feature engineering
* Train and evaluate multiple machine learning models
* Compare model performance using standard evaluation metrics
* Understand factors contributing to cancer recurrence

## 📂 Dataset & Preprocessing

* Structured dataset containing clinical and patient attributes
* Handled missing values and categorical variables
* Performed normalization and feature selection
* Split data into training and testing sets


## 🧠 Machine Learning Models

The following models were implemented and evaluated:

* Random Forest
* Support Vector Machine (SVM)
* Logistic Regression
* XGBoost
* Decision Tree
* Gradient Boosting
* Stacking
* Blending

Model comparison was conducted to identify the most effective approach for recurrence prediction.

## ⚙️ Technologies Used

* Python
* Scikit-learn
* Pandas
* NumPy
* Matplotlib

## 📊 Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

These metrics were used to assess predictive performance and model reliability.

## 📈 Results & Findings

* Successfully trained machine learning models for predicting thyroid cancer recurrence
* Observed variation in performance across different algorithms
* Identified influential features affecting recurrence outcomes
